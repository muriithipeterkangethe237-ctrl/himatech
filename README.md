## Website

The Hemitech Kenya website is available in `index.html`. To preview it locally, install Python 3 and run:

```bash
python server.py
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000) in a browser. The server uses only Python's standard library.

The Products section includes selected specifications and regional price guides from the supplied documents, including Ruijie Reyee access points, outdoor wireless equipment, routers, and Grandstream products. Original datasheets and price lists are available from the website under `assets/`. Prices, variants, tax treatment, and stock are subject to confirmation.

The public website is published with GitHub Pages. Search engines can discover its homepage through [`sitemap.xml`](https://muriithipeterkangethe237-ctrl.github.io/HEMITECH-KENYA/sitemap.xml); `robots.txt` advertises the sitemap location.
